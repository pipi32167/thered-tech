## 📚 关于

这是一个专门记录**被淘汰、过时、失败的技术**的 Zettelkasten（卡片盒笔记）知识库。每个笔记都深入探索一个"枯萎"的技术，分析其历史、影响、失败原因和现代启发。

- 从失败中提取智慧
- 寻找技术"重生"的可能性

## 💡 什么是"枯萎技术"？

不是"进化"的技术（如马车→汽车），而是：
- ❌ 完全失败并被遗忘
- ❌ 生不逢时的天才想法
- ❌ 被时代淘汰但仍值得研究
- ✅ 从中提取跨时代的智慧
