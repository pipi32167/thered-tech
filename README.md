# 枯萎技术卡片笔记盒

> 一个用 Zettelkasten 方法组织的枯萎技术知识网络

## 🏛️ 关于这个笔记盒

这个笔记盒使用卢曼的卡片盒笔记法（Zettelkasten Method）组织，专注于探索被淘汰、过时、失败的技术及其现代价值。

## 📁 笔记类型

### 1. 速记笔记 (Fleeting Notes)
- 临时记录的想法和观察
- 待整理的枯萎技术片段
- 快速捕捉的灵感

**位置**: `fleeting/`

### 2. 文献笔记 (Literature Notes)
- 阅读技术史资料的摘录
- 历史文献的总结
- 研究发现的记录

**位置**: `literature/`

### 3. 永久笔记 (Permanent Notes)
- 经过思考的核心观点
- 技术分析的结论
- 可独立理解的原子化知识

**位置**: `permanent/`

### 4. 结构笔记 (Structure Notes)
- 技术之间的连接
- 主题索引
- 概念地图

**位置**: `structure/`

### 5. 索引笔记 (Index Notes)
- 笔记盒的导航入口
- 核心概念的汇总
- 重要链接的集合

**位置**: `index/`

## 🔗 编号系统

使用层级编号系统：
- `WT-001`: 永久笔记主编号
- `WT-001a`: 主笔记的子笔记
- `WT-001-2026`: 与该笔记相关的年度笔记

**WT = Withered Technology**

## 🎯 核心原则

### 1. 原子化
每则笔记只记录一个技术或一个核心观点

### 2. 独立性
每则笔记应该能独立理解，不依赖上下文

### 3. 链接性
- 使用 `[[笔记编号]]` 创建内部链接
- 使用 `[[技术名称]]` 创建主题链接
- 记录笔记之间的关系：继承、对比、启发

### 4. 唯一性
每个技术/概念只创建一个永久笔记

## 🔍 标签系统

### 领域标签
- `#ancient`: 古代技术
- `#industrial`: 工业时代
- `#digital`: 数字时代
- `#biotech`: 生物技术
- `#craft`: 工艺技术
- `#transport`: 交通工具
- `#communication`: 通信技术
- `#agriculture`: 农业技术

### 状态标签
- `#extinct`: 完全淘汰
- `#dormant`: 暂时沉寂，可能重生
- `#evolved`: 演化为其他形式
- `#failed`: 失败的实验

### 启发标签
- `#reusable`: 可直接重用
- `#inspiring`: 有启发价值
- `#warning`: 失败教训
- `#philosophical`: 哲学思考

## 🌐 技术联系网络

这个笔记盒的核心价值在于发现枯萎技术之间的联系：

### 时间维度
- 古代技术 → 工业技术 → 现代技术
- 技术的"轮回"和"重现"

### 空间维度
- 不同文化独立发展的相似技术
- 技术传播的路径

### 功能维度
- 解决相同问题的不同方案
- 技术的"殊途同归"

### 哲学维度
- 技术兴衰的规律
- 创新的边界和可能

## 📊 使用指南

### 如何添加新笔记
1. 在 `fleeting/` 记录初步想法
2. 研究后整理到 `literature/`
3. 提炼核心观点到 `permanent/`
4. 建立链接到 `structure/`
5. 更新 `index/`

### 如何探索笔记盒
1. 从 `index/README.md` 开始
2. 跟随感兴趣的链接
3. 发现意外的连接
4. 形成自己的理解

## 🔄 持续演化

这个笔记盒是活的：
- 笔记会不断被重新组织和链接
- 新的连接会被发现
- 旧的理解会被更新

**核心目标**: 不是建立一个静态的档案馆，而是一个动态的知识网络。
