# WT-055: Waru Waru - 抬田式农业系统

**领域**: 农业生态学 / 高原农业

## 🏛️ 技术概述

Waru Waru（也称Camellones）是安第斯高原古代文明（主要是Tiwanaku文化，约公元500-1000年）发明的抬田式农业系统。在这个系统中，农民挖掘浅渠形成土垄，在垄上种植作物。渠道中的水分和有机物质通过毛细作用滋润土壤，同时创造微气候调节温度。

## 📜 发展简史

Waru Waru诞生于安第斯高原（今玻利维亚和秘鲁交界），海拔约3800米的的喀喀湖盆地。这里的农业挑战极端：昼夜温差可达25°C，干旱频发，土壤贫瘠。古代Tiwanaku人发现，通过挖掘浅沟渠（约1-2米深）堆叠成垄（宽4-10米），可以创造一个人工湿地生态系统。渠道养鱼、收集雨水、堆积有机淤泥，垄上种植马铃薯、藜麦等作物。这种系统支持了Tiwanaku帝国的繁荣，使其成为前哥伦布时期南美洲最大的政治实体之一。

## ⚰️ 枯萎原因

*多重因素叠加导致崩溃*：

1. **气候变化**：公元1000年左右，该地区发生持续干旱，Waru Waru依赖的水源枯竭
2. **社会崩溃**：Tiwanaku帝国政治解体，维护这种劳动密集型系统的社会组织瓦解
3. **欧洲征服**：西班牙殖民者推行欧洲式矩形农田，破坏原有系统
4. **认知断层**：Waru Waru的生态智慧需要代际传承，一旦中断，数十年内消失

## 💡 当代启发

**正在重生**：1980年代，安第斯农民开始恢复Waru Waru。1990年代联合国开发计划署支持"Proyecto Camellones"项目，恢复5000公顷。结果显示，与传统农田相比：
- 产量提高2-3倍
- 抗霜冻能力增强（水温调节微气候）
- 减少灌溉需求50%

**现代启示**：
1. **生态工程**：人工创造"生产性湿地"，农业与水产结合
2. **气候适应**：利用水的热容特性缓解极端温度
3. **分布式水利**：去中心化的微蓄水系统，而非依赖大型工程
4. **遗产农业**：古代技术可能提供气候变化的解决方案

**可能的应用场景**：
- 高原、干旱地区的农业恢复
- 城市农业的垂直抬田设计
- 湿地修复与农业生产结合
- 碳中和农业模型
