# WT-252 蓝晒法 (Cyanotype)

## 基本信息

**技术名称**：蓝晒法 / 蓝图
**领域**：摄影 / 建筑 / 工程
**诞生时间**：1842年
**发明者**：约翰·赫歇尔爵士 (Sir John Herschel)
**枯萎时间**：20世纪中期（被复印机和现代印刷技术取代）

## 技术简史

约翰·赫歇尔爵士于1842年发明了这种简单优雅的摄影工艺。他将柠檬酸铁铵和铁氰化钾按比例混合，涂布在纸上，干燥后制成感光纸。当紫外线照射时，两种化合物发生光化学反应，生成不溶于水的普鲁士蓝色沉淀。未经曝光的部分可被水洗去，形成蓝底白线的图像。

1860年代，蓝晒法被改良用于工程图纸复制，"蓝图"一词由此而来。建筑师和工程师用半透明的墨水在描图纸上绘制，然后覆盖在蓝晒纸上曝光，得到精确的负像复制。这种方法成本低、操作简单、保存时间长，统治了工程制图领域近百年。20世纪中期，复印机和数字化绘图技术出现，蓝晒法逐渐退出历史舞台。

## 枯萎原因

1. **技术替代**：静电复印（施乐）技术出现，可直接得到正像，速度更快
2. **效率问题**：蓝晒需要自然光或强紫外线光源，曝光时间长（数分钟到数十分钟）
3. **工作流程**：需要制作描图纸、曝光、水洗、干燥多个步骤，流程繁琐
4. **颜色限制**：只能产生蓝色图像，工程应用中阅读性不如黑白图纸清晰
5. **存储问题**：蓝晒纸在光照下会继续变深，长期保存需要避光

## 当代启发

蓝晒法在摄影艺术和手工制作领域迎来"文艺复兴"：

1. **艺术价值**：独特的普鲁士蓝色调具有强烈的审美价值，被当代摄影师和艺术家重新发现
2. **教育意义**：因其安全无毒（不像银盐摄影含重金属），成为学校科普光化学原理的理想材料
3. **可持续理念**：手工制作、材料简单、可生物降解，符合现代对可持续生活方式的追求
4. **技术哲学**：展示了"足够简单"的技术如何产生深刻美感——柠檬酸铁铵和铁氰化钾两种普通化学品，加上阳光和水，就能创造出永恒的图像
5. **"慢技术"运动**：在即时成像和数字滤镜的时代，蓝晒法代表的等待、手工、不可复制的独特性，成为对抗技术同质化的文化实践

## 技术细节

**化学反应**：
```
3Fe2(C6H5O7)2 + 2K3[Fe(CN)6] + hν → Fe3[Fe(CN)6]2 + 6K[C6H5O7]
柠檬酸铁铵 + 铁氰化钾 + 光 → 普鲁士蓝沉淀
```

**流程**：
1. 配方：溶液A（柠檬酸铁铵）+ 溶液B（铁氰化钾），使用时等量混合
2. 涂布：在暗处均匀涂布于水彩纸或其他载体
3. 曝光：放置阴底底片或实物，置于阳光下或紫外线灯下曝光5-15分钟
4. 显影：流动清水冲洗，图像逐渐显现
5. 漂白（可选）：使用过氧化氢或稀醋酸调整色调
6. 干燥：自然晾干
