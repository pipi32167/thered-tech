## 技术概述

古代鎏金镀锡技术是利用化学和物理方法在金属或非金属表面镀覆金、银、锡等金属薄层的传统装饰工艺。包括"火镀金"（鎏金）和"热浸锡"（镀锡）两大类。

**核心技术特点：**
- **鎏金**：利用汞（水银）溶解金形成金汞齐（ amalgam ），涂覆于器物表面，加热蒸发汞后留下金层
- **镀锡**：将锡熔化后涂覆于铁器、铜器表面，防止锈蚀
- **厚度控制**：鎏金层厚度通常为2-10微米
- **附着力**：与基体金属结合牢固

**技术分类：**
- **按工艺**：鎏金、镀锡、镀银、镀铜
- **按应用**：建筑装饰、器皿装饰、防锈处理
- **按地域**：中国、埃及、希腊、罗马、印度

## 技术原理

### 鎏金工艺（火镀金）

**工艺流程：**

1. **制汞齐（金汞齐制备）**
   - 将纯金锤打成薄金箔
   - 将金箔剪碎
   - 加入汞（水银）
   - 加热至400-500°C
   - 金溶解于汞形成金汞齐（AuHg₂）

2. **表面处理**
   - 基体金属表面清洁
   - 酸洗去油污
   - 打磨平整

3. **涂汞齐**
   - 将金汞齐涂覆于器物表面
   - 用工具压实
   - 形成均匀薄层

4. **烘烤（蒸发汞）**
   - 加热至500-600°C
   - 汞蒸发（沸点356°C）
   - 金原子结合形成金层
   - 汞蒸气通过冷凝回收

5. **平整抛光**
   - 用玛瑙石抛光
   - 使金层光亮
   - 增加附着力

**化学原理：**
- **汞齐化**：金与汞形成金属间化合物
- **汞蒸发**：加热后汞挥发，留下纯金
- **金扩散**：金原子与基体金属结合

### 镀锡工艺（热浸锡）

**工艺流程：**

1. **表面处理**
   - 酸洗除锈
   - 碱洗去油
   - 清水冲洗

2. **助镀剂**
   - 氯化锌溶液（ZnCl₂）
   - 氯化铵溶液（NH₄Cl）
   - 涂覆于表面

3. **热浸锡**
   - 将锡加热熔化（熔点232°C）
   - 将工件浸入锡液
   - 温度：300-400°C

4. **冷却固化**
   - 取出工件
   - 自然冷却
   - 锡层固化

5. **抛光处理**
   - 打磨平整
   - 提高光泽

**化学原理：**
- **润湿性**：助镀剂提高锡液润湿性
- **合金化**：锡与铁表面形成合金层（FeSn₂）
- **牺牲阳极**：锡先于铁腐蚀，保护铁基体

### 影响因素

**温度控制：**
- 鎏金烘烤温度：500-600°C（过高金熔化）
- 镀锡锡液温度：300-400°C

**时间控制：**
- 鎏金烘烤时间：10-30分钟
- 镀锡浸入时间：数秒至数分钟

**材料纯度：**
- 金纯度：99.99%
- 锡纯度：99.5%以上

**表面状态：**
- 表面粗糙度影响附着力
- 油污、锈迹影响镀层质量

## 枯萎原因分析

### 鎏金的致命缺陷（技术原因）

**汞中毒（Mercury Poisoning）：**
- **职业健康危害**：工匠长期接触汞蒸气
- **神经系统损伤**：震颤、共济失调、精神异常
- **寿命缩短**：鎏金匠人平均寿命仅40-50岁
- **不治之症**：古代无有效治疗方法

**环境污染：**
- **汞蒸气挥发**：污染大气、土壤
- **汞积累**：在食物链中富集
- **长期污染**：古代鎏金作坊遗址至今汞超标

**工艺缺陷：**
- **金层不均**：手工涂覆厚度不均
- **附着力有限**：金层易剥落
- **修补困难**：剥落后需重新鎏金

### 镀锡的局限性

**性能限制：**
- **锡层较软**：易划伤
- **耐温性差**：锡在13°C以下转变为粉末状（锡疫）
- **厚度控制难**：热浸锡厚度不易控制

**材料成本：**
- **锡价格波动**：锡是战略物资
- **产量限制**：锡矿分布不均

### 技术替代

**电镀技术兴起（19世纪末）：**
- **1880年代**：电镀金发明
- **优势**：
  - 无汞毒性
  - 厚度可控（微米级）
  - 附着力强
  - 可大规模生产
- **效率**：成本仅为鎏金的1/5-1/3

**热浸镀锌（Galvanizing）：**
- **19世纪**：大规模应用
- **防锈效果**：优于镀锡
- **成本**：仅为镀锡的1/2
- **工业化**：适合大规模生产

**粉末涂料（20世纪）：**
- **1950年代**：发明
- **装饰效果**：仿金色、银色
- **成本**：极低
- **环保**：无毒
