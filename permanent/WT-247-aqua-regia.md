# WT-247: 王水（Aqua Regia）

**领域**: 化学/冶金

**简史**: 王水诞生于8世纪阿拉伯炼金术，由盐酸和硝酸按3:1混合而成。它能溶解金、铂等"贵金属"，被誉为"皇家之水"。炼金术士用它试图实现"金属转化"——将贱金属变成黄金。

**枯萎原因**:
- **理论破产**: 炼金术的"金属转化"理论被现代化学否定
- **发现真相**: 19世纪化学家发现，金被溶解后仍可回收，并未发生本质转化
- **危险操作**: 王水产生剧毒氯气和亚硝酰氯，炼金术士常因此中毒
- **方法冗余**: 现代冶金有更高效、更安全的溶解技术

**历史影响**:
- 推动了酸碱化学的早期发展
- 促进了溶解和沉淀理论的形成
- 启发了对"贵金属"化学性质的研究
- 1940年，科学家用王水溶解诺贝尔奖金牌以避纳粹搜查——这可能是它最"传奇"的应用

**当代启发**:
1. **跨界思维**: 炼金术虽是伪科学，但炼金术士发明的王水至今是实验室必备试剂
2. **错误理论的副产品**: 错误的终点理论可能孕育正确的工具——王水溶解金的事实，揭示了金可以被氧化的化学原理
3. **现代应用**: 王水仍用于精炼黄金、蚀刻电路板、分析贵金属成分
4. **教训警示**: 目标的荒谬性不等于工具的无用性——炼金术士想要"点石成金"是妄想，但他们开发的化学工具却实实在在推动了科学

**重生可能**: 王水从未真正"消亡"，只是从炼金术士的密室走进了化学实验室。它的存在证明：人类的探索欲是双刃剑——它会催生妄想，也会催生突破。
