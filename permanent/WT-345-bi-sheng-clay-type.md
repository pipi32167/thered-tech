# WT-345: 毕昇泥活字印刷术

**领域**: 印刷技术 / 文明传播工具

## 简史

北宋庆历年间（1041-1048年），平民毕昇发明了泥活字印刷术。他将胶泥制成字块，用火烧硬，排版时将活字排列在铁板上，用松脂、蜡和纸灰混合物固定，压平后即可印刷。毕发明的泥活字比古腾堡的金属活字早了约400年。

## 枯萎原因

泥活字印刷术虽然技术突破巨大，但在中国未能普及：

1. **汉字数量庞大**：常用字数千，需要制作大量活字，成本高且管理困难
2. **泥字耐久性差**：泥质活字易碎，不耐长期反复使用
3. **雕版更适应汉字**：对于汉字这种方块文字，整版雕版在某些场景下更高效
4. **文化传承路径**：技术未能形成产业规模，技艺传承受限
5. **社会需求结构**：当时的书籍需求量和种类尚未达到需要灵活排版的高度

后被木活字（王祯1298年）、铜活字（华燧1490年）和金属活字（朝鲜13世纪）逐步取代。

## 历史影响

1. 证明了"活字拼版"概念的可行性，是人类第一次系统性使用可重复使用字符进行印刷
2. 推动了宋代的书籍传播，促进了文化普及
3. 为后来的木活字、铜活字提供了技术范式
4. 通过丝绸之路可能间接影响了中亚和欧洲的印刷思想

## 当代启发

1. **技术移植的文化适应性**：同样的技术在不同文明中需要调整才能扎根
2. **"过早"的创新**：有时技术本身是先进的，但配套环境（文字系统、市场需求、产业链）未跟上
3. **材料科学的关键性**：印刷术的革命最终需要金属材料学的进步才能成熟
4. **知识传播的复杂性**：优秀技术若没有合适的传播路径和社会结构，也会"枯萎"

在数字时代，汉字排版最终通过Unicode和输入法实现了"活字"的彻底胜利——但这已经是计算机时代了。
