# WT-1000: 计算尺

## 🏛️ 技术信息
- **领域**: 计算/数学工具
- **时期**: 1620-1970年代（约350年）
- **核心**: 对数刻度的模拟计算器

## 📜 简史
1620年，英国数学家威廉·奥特雷德发明计算尺，基于约翰·纳皮尔的对数原理。通过将数字按对数刻度排列在滑动尺上，将乘除法转化为加减法的滑动操作。此后350年间，计算尺成为工程师、科学家、建筑师的标配工具。1960年代仍是NASA航天工程师的核心计算设备。

## ⚙️ 技术原理
- 利用对数性质：log(ab) = log(a) + log(b)
- 乘法转换为长度加法，除法转换为长度减法
- 精度通常为3位有效数字，熟练者可快速计算
- 后来发展出多种专用尺：电工尺、化学尺、航空尺

## 🌍 历史影响
- **工业革命引擎**：工程师能快速完成桥梁、机械、电路计算
- **科技发展**：从铁路到原子弹，计算尺参与设计
- **教育符号**：工程师颈挂计算尺成为身份象征
- **战争影响**：二战炮兵弹道计算依赖专用计算尺

## ⚰️ 枯萎原因
**致命的替代品**：
1. **电子计算器**：1972年HP-35便携科学计算器问世
2. **精度压制**：电子计算轻松达到10位以上精度
3. **速度碾压**：毫秒级计算 vs 秒级操作
4. **价格革命**：1970年代后期计算器价格暴跌至大众可承受

**1972-1975年的3年内，350年的统治地位崩塌**。NASA工程师在阿波罗计划后期仍使用计算尺，但到了航天飞机时代已完全被电子计算取代。

## 💡 当代启发

### 1. 估算思维的价值
计算尺培养的"量级感知"在电子时代反而被削弱。工程师如今过度依赖精确结果，常忽略数量级是否合理。**启发：在现代工具链中保留"快速估算"环节**。

### 2. 可视化计算体验
计算尺的物理操作让数学关系直观可见。现代软件的"黑盒化"让用户失去对函数关系的直觉理解。
**应用：教育科技中引入可视化、可操纵的数学工具**。

### 3. 后备系统的思考
计算尺不需要电池，可靠性和耐用性极强。在极端环境下（太空、野外），模拟工具可能是最后的保障。
**案例：阿波罗13号宇航员曾手动计算轨道，类似思维可用于紧急备份设计**。

### 4. 专业化与通用化的辩证
计算尺后期分化出众多专业版本，这最终被通用电子计算器取代。**教训：过度细分的专用工具会被强大的通用平台吞噬**——这可能是当前垂直SaaS的警钟。

### 5. "足够好"的技术哲学
计算尺的3位精度对绝大多数工程任务已足够。但技术常走向"过度精确"。
**反思：现代软件是否在用户不需要的维度上过度优化？**

### 6. 技能消失的代价
熟练使用计算尺需要理解数学原理，而计算器只需按键。**自动化工具降低了门槛，但也削弱了对原理的理解**——这对AI辅助编程、设计等领域有警示意义。
