# WT-1085 相机暗箱技术

## 概览

**技术名称**：相机暗箱

**活跃时期**：公元前5世纪-19世纪中叶（约2300年）

## 技术核心

### 光学原理

**1. 针孔成像**
- **基本原理**：
  - 光线直线传播
  - 通过小孔形成倒像
  - 物距越大，像越小

- **成像规律**：
  ```
  像高 / 物高 = 像距 / 物距
  像距 + 物距 ≈ 暗箱深度（针孔模式）
  ```

**2. 透镜成像**（16世纪后）
- **凸透镜聚焦**：
  - 平行光线汇聚
  - 形成清晰图像
  - 亮度提升

- **成像公式**：
  ```
  1 / f = 1 / u + 1 / v
  f: 焦距，u: 物距，v: 像距
  ```

### 暗箱类型

**1. 房间式暗箱**
- **建筑暗室**：
  - 整个房间变暗
  - 墙上开小孔
  - 多人同时观察

- **著名案例**：

  - 伦敦皇家学会演示（17世纪）

**2. 携带式暗箱**

  - 简单轻便
  - 艺术家写生

- **箱式**：

**3. 折叠式暗箱**

  - 便于描摹

### 操作技术

**1. 设置暗箱**
- **遮光准备**：
  - 选择暗室或搭建暗箱
  - 密封所有缝隙
  - 确保完全黑暗

**2. 安装镜头**
- **针孔模式**：
  - 钻孔（直径1-3毫米）
  - 光滑边缘减少衍射

- **透镜模式**：
  - 安装凸透镜
  - 调节焦距
  - 瞄准景物

**3. 调节图像**
- **对焦**：
  - 移动投影屏
  - 调整物距
  - 获得清晰图像

- **亮度控制**：
  - 针孔大小
  - 透镜孔径
  - 外界光照

**4. 描绘图像**
- **固定画纸**：
  - 放置在投影屏上
  - 对准图像位置

- **描绘轮廓**：
  - 描绘图像边缘
  - 添加细节
  - 复制光影

## 枯萎原因

### 技术局限

**1. 图像质量**
- **亮度不足**：
  - 针孔模式很暗
  - 透镜模式仍有限
  - 仅适合强光环境

- **分辨率限制**：
  - 针孔边缘衍射
  - 透镜像差
  - 清晰度有限

**2. 操作复杂**
- **环境要求**：
  - 需暗室或暗箱
  - 携带不便
  - 设置繁琐

- **依赖光线**：
  - 仅白天可用
  - 阴天效果差
  - 夜间无法使用

**3. 实时观察**
- **无法记录**：
  - 只能现场观察
  - 必须立即描绘
  - 无法保存图像
