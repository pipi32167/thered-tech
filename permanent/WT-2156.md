# WT-2156：中国玻璃摄影术（湿版火棉胶工艺）

## 技术概述

**技术时期**：19世纪60年代-20世纪30年代（约70年）
**技术领域**：摄影/影像技术/化学工艺/暗房技术
**技术类型**：玻璃底片摄影/湿版工艺/早期摄影技术

### 技术定义

中国玻璃摄影术是指19世纪60年代传入中国的湿版火棉胶（Collodion Wet Plate）摄影工艺，通过在玻璃板上涂布火棉胶、硝酸银敏化、在湿润状态下曝光拍摄，现场制作玻璃底片的摄影技术。每张玻璃底片都是独一无二的原作，无法批量复制，是摄影艺术与技术结合的巅峰。

### 核心特征

1. **现场制作**：必须现场制作玻璃底片，拍摄后立即冲洗
2. **原作唯一性**：每张照片都是独一无二的原作
3. **工艺复杂**：需要掌握化学、光学、暗房技术
4. **设备笨重**：暗箱、玻璃板、化学药剂等重达数十公斤
5. **技术门槛高**：需要专业知识和技术
6. **艺术价值高**：玻璃底片质感独特，历史价值高

## 技术原理详解

### 湿版火棉胶工艺

**涂布火棉胶**：
1. 清洁玻璃板
2. 涂布火棉胶（硝酸纤维素溶液）
3. 形成均匀薄膜
4. 暗房中干燥

**硝酸银敏化**：
1. 准备硝酸银溶液
2. 将涂布火棉胶的玻璃板浸入
3. 形成感光碘化银
4. 暗房中干燥

**曝光拍摄**：
1. 在湿润状态下装入相机
2. 对准拍摄对象
3. 控制曝光时间（数秒至数分钟）
4. 保持玻璃板湿润

### 显影定影

**显影**：
1. 硫酸亚铁溶液
2. 显影数分钟
3. 影像显现
4. 水洗停止显影

**定影**：
1. 氰化钾溶液
2. 定影数分钟
3. 影像固定
4. 水洗去除定影液

**干燥保存**：
1. 晾干
2. 上清漆保护
3. 玻璃底片完成

### 设备系统

**相机**：
- 大型木制相机
- 皮腔调节焦距

**暗箱**：

## 技术教训与警示

### 技术替代的双面性

**胶卷的优势**：
- 可批量复制
- 可延迟冲洗
- 使用便利

**代价**：
- 失去"原作唯一性"
- 失去"创作仪式"
- 失去"材料记忆"

**警示**：
- 技术进步应该保留多样性
- 不是所有领域都需要"最高效率"
- "慢技术"在艺术维度有价值

### 口传技艺脆弱性

**失传的教训**：
- 火棉胶配方、硝酸银溶液配制等失传
- 传承链条断裂
- 口传技艺无法应对社会变迁

**警示**：
- 传统技艺必须系统化记录
- 现代技术需要文档化
- 开源文化是知识传承保障

### 化学安全

**危险化学药剂**：
- 火棉胶易爆炸
- 硝酸银有毒
- 许多摄影师受伤或中毒

**警示**：
- 技术发展必须考虑安全性
- 不能以牺牲健康为代价
- 安全第一原则

### 设备便携性

**笨重设备**：
- 暗箱重达数十公斤
- 相机笨重
- 不便携带

**启示**：
- 设备设计应该便携化
- 技术发展应该轻量化
- 便利性很重要
