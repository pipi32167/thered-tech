# WT-148: 镭发光涂料工艺

**领域**: 材料科学 / 工业化学 / 劳工安全

## 📜 简史

1910年代，玛丽·居里发现镭后，这种神奇元素被视为"健康的能量"。美国镭公司开发出含镭荧光涂料，用于军表、飞机仪表和钟表刻度。数百名年轻女性被雇佣为"镭女郎"，在工厂中用唇笔尖蘸取涂料描绘数字。她们被告知这是无害的，甚至在派对上用发光涂料涂抹身体取乐。

## ⚰️ 枯萎原因

**1920年代末，首批"镭女郎"开始死亡**：
- 下颌骨坏死（"镭颚"）
- 贫血、骨折、肿瘤
- 尸体放射性可被探测

1938年，镭涂料被彻底禁用。物理学家哈里森·马尔泰尔发现镭会在骨骼中富集，取代钙，持续发射α粒子破坏组织。

## 💡 当代启发

1. **"未知风险"的代价** - 技术乐观主义常忽视长期健康影响
2. **劳动者知情权** - 现代OSHA法规、化学品安全数据表的起源
3. **独立研究的重要性** - 公司内部研究掩盖真相，独立学者揭露真相
4. **现代类似案例** - 纳米材料、AI偏见、社交媒体心理影响
