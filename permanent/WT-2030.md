# WT-2030：中国古代斗彩瓷器技术

## 元数据
- **技术时期**：明代成化年间（1465-1487年）-20世纪中叶（约500年）
- **技术领域**：陶瓷工艺/釉上彩装饰/手工业
- **核心特征**：釉下青花+釉上彩结合、二次烧成、色彩艳丽
- **枯萎时间**：20世纪中叶工业化取代
- **现代状态**：非遗保护、高端收藏、现代复原

---

## 1. 技术概述

### 1.1 技术定义
斗彩瓷器技术是中国明代成化年间（1465-1487年）景德镇发明的一种陶瓷装饰工艺，将釉下青花与釉上多彩装饰相结合，创造"青花"与"彩绘"争奇斗艳的艺术效果。其核心创新在于"二次烧成"工艺：先在1300°C高温下烧成釉下青花瓷器，再在800°C低温下进行釉上彩绘和二次烧成。这是中国陶瓷装饰技术的重大突破，代表了中国陶瓷工艺从单一釉下装饰向釉下釉上结合装饰的转型。

### 1.2 核心原理
1. **釉下青花**：先用钴料在瓷胎上绘图案，高温一次烧成
2. **釉上彩绘**：在青花瓷器上用多种彩料二次绘制
3. **二次烧成**：低温烧制使釉上彩料固定
4. **色彩融合**：青花蓝与釉上彩形成和谐对比
5. **工艺复杂**：需两次入窑，技术要求极高

### 1.3 技术特点
- **胎薄釉润**：成化斗彩以胎质细腻、釉色莹润著称
- **色彩艳丽**：红、绿、黄、紫等多种色彩
- **画工精细**：纹饰绘制极为精致
- **独具特色**：与五彩、珐琅彩等工艺有明显区别

## 3. 技术原理详解

### 3.1 制备工艺

#### 3.1.1 胎体制备
- **瓷土选择**：
  - 高岭土（景德镇特产）
  - 瓷石
  - 配比精确

- **成型**：
  - 拉坯、印坯、雕镶
  - 阴干
  - 修坯

#### 3.1.2 素烧
- **高温烧成**：
  - 温度：1300°C左右
  - 气氛：还原焰
  - 时间：数日
  - 形成瓷胎

### 3.2 釉下青花绘制

#### 3.2.1 青花料
- **钴料来源**：
  - 进口"苏麻离青"（早期）
  - 国产"浙料"、"珠明料"
  - 化学成分：钴铝酸钴

- **绘制**：
  - 笔绘图案轮廓
  - 淡水晕染效果
  - 分水技法

### 3.3 第一次烧成（高温）

#### 3.3.1 烧制
- **温度控制**：
  - 1300°C
  - 还原气氛
  - 保温时间

- **效果**：
  - 青花呈色
  - 釉面熔融
  - 瓷器致密

### 3.4 釉上彩绘制

#### 3.4.1 彩料种类
- **矾红**（铁红）：
  - 氧化铁
  - 红色
  - 主要色彩

- **绿彩**（铜绿）：
  - 氧化铜
  - 绿色
  - 辅助色彩

- **黄彩**（锑黄）：
  - 氧化锑
  - 黄色
  - 点缀色彩

- **紫彩**（锰紫）：
  - 氧化锰
  - 紫色
  - 罕见色彩

#### 3.4.2 绘制技法
- **填彩**：
  - 在青花轮廓内填彩
  - 厚度均匀
  - 不出轮廓

- **点染**：
  - 局部点缀
  - 增加层次
  - 突出重点

### 3.5 第二次烧成（低温）

#### 3.5.1 低温烧制
- **温度**：
  - 700-800°C
  - 远低于第一次烧成
  - 保护釉面

- **气氛**：
  - 氧化焰
  - 彩料显色

- **时间**：
  - 数小时至一日
  - 精确控制
