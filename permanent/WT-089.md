# WT-089: 氡健康疗法 (Radon Therapy)

**🏛️ 领域**: 医学/健康

**📜 简史**:
20世纪初至1960年代，氡气被误认为有益健康。欧美开设大量"氡气洞"（radon caves）和温泉疗养院，宣称吸入放射性氡气可治疗风湿、关节炎、不孕症等。甚至有"放射性水"和"氡气注射液"产品。直至1960年代辐射危害被确认，才逐渐淘汰。

**⚰️ 枯萎原因**:
**致命的认知错误**——将"低剂量辐射刺激效应"误解为普遍益处。实际上，氡气衰变产生的α粒子会破坏DNA，导致肺癌。它是第二大肺癌病因（仅次于吸烟）。1950-60年代，流行病学研究揭示铀矿工人肺癌高发与氡暴露直接相关。现代科学证明：**任何剂量的氡暴露都有致癌风险，无安全阈值**。

**💡 当代启发**:
这场医疗悲剧带来深刻警示：

1. **伪科学的巨大代价**——建立在错误理论基础上的"疗法"可能造成几代人的健康损害

2. **"自然≠安全"的永恒教训**——放射性矿泉、某些草药、"天然"疗法同样需要严格科学验证

3. **监管滞后于科学**——氡疗法兴盛时，辐射危害尚未被充分理解；今天AI、基因编辑等新技术同样面临"未知风险"的挑战

4. **现代启示**：许多国家仍有合法氡疗院（如德国、奥地利、日本），争议持续。这提醒我们：**医学决策必须基于循证证据，而非传统或商业利益**
