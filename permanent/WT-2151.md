# WT-2151：中国古代青铜器陶范铸造技术

## 技术概述

**技术时期**：夏代-东汉（约公元前2000年-公元3世纪，约2300年）
**技术领域**：冶金/铸造工艺/青铜技术/工艺美术
**技术类型**：陶范铸造技术/分铸技术/失蜡法技术

### 技术定义

中国古代青铜器陶范铸造技术是指用陶土制成外范和内范形成空腔，然后浇注铜液铸造青铜器物的技术体系。这是中国青铜文明的核心技术，创造了司母戊鼎、四羊方尊等举世闻名的青铜重器，支撑了夏商周三代青铜文明约2000年。

### 核心特征

1. **陶范材料**：用陶土制作模具，可耐高温
2. **分范合铸**：复杂器物分块铸造后组装
3. **技术复杂**：需制模、制范、浇注、清理、打磨多道工序
4. **一器一范**：每件青铜器都有独特的模具
5. **规模宏大**：可铸造数百公斤的大型器物
6. **艺术价值**：青铜器是艺术与技术的完美结合

## 历史发展

### 起源期（夏代-商代早期，公元前2000年-公元前14世纪）

**夏代起源**：
- 二里头文化（约公元前1900-1500年）出土早期青铜器
- 青铜爵、青铜戈等简单器物
- 陶范铸造技术初步形成

**早期技术**：
- 简单的单范铸造
- 器物较小，造型简单
- 主要为兵器、酒器

**技术特点**：
- 陶范材料：粘土、砂、草木灰混合
- 浇注系统：简单的浇口和冒口
- 合金成分：铜锡铅合金

### 成长期（商代中期-西周，公元前14世纪-公元前8世纪）

**商代技术突破**：
- 发明分范合铸技术
- 可铸造复杂造型器物
- 司母戊鼎（832公斤）代表技术巅峰

**技术进步**：
- **分范技术**：将复杂器物分解为多个部分
- **陶范拼合**：多块陶范拼合形成完整型腔
- **泥芯支撑**：用泥芯形成器物内腔
- **浇注系统**：完善的浇口、冒口、排气道

**商代代表作**：
- 司母戊鼎：832公斤，世界最大青铜器
- 四羊方尊：复杂造型，分铸技术巅峰
- 青铜立人像：三星堆，高2.6米

**西周继承发展**：
- 继承商代技术
- 铭文技术发展（长篇铭文）
- 礼器制度完善

**技术特点**：
- 陶范制作精细
- 分铸技术成熟
- 可铸造超大型器物

### 鼎盛期（春秋战国，公元前8世纪-公元前3世纪）

**技术革新**：
- 发明失蜡法（熔模铸造）
- 叠铸技术（一范多铸）
- 表面装饰技术（镶嵌、鎏金、错金银）

**失蜡法**：
- 用蜡制作模型
- 外敷陶土形成外范
- 加热熔化蜡形成型腔
- 可铸造极复杂造型

**春秋代表作**：
- 曾侯乙编钟：64件，音律准确
- 莲鹤方壶：造型优美，技术精湛
- 越王勾践剑：千年不锈

**技术特点**：
- 失蜡法成熟
- 装饰技术精湛
- 音律技术（编钟）

### 衰落期（秦汉-东汉，公元前3世纪-公元3世纪）

**秦汉时期**：
- 铁器兴起，青铜地位下降
- 礼制变革，青铜礼器需求减少
- 青铜转向实用器物（铜镜、铜钱）

**技术转型**：
- 大型礼器铸造减少
- 小型实用器物增加
- 技术简化

**东汉终结**：
- 礼制变革，青铜礼器需求暴跌
- 陶范技术仅用于铜镜、铜钱
- 传统技术失传

**失传原因**：
- 技术传承断裂
- 需求消失
- 铁器取代

## 技术原理详解

### 陶范制作

**材料准备**：
1. 选取粘土（细粘土）
2. 加入砂（增加透气性）
3. 加入草木灰（增加透气性）
4. 混合均匀
5. 练泥（反复揉捏）

**制范工艺**：
1. **制模**：制作器物模型（木模或泥模）
2. **翻范**：用模压制陶范
3. **晾干**：自然阴干（数周）
4. **焙烧**：低温焙烧（800-900°C）
5. **修整**：修整范面，雕刻纹饰

**陶范类型**：
- **外范**：形成器物外形
- **内范**（泥芯）：形成器物内腔
- **范芯**：支撑泥芯

### 分铸技术

**分范设计**：
- 将复杂器物分解为多个部分
- 每部分独立铸造
- 然后组装成整体

**分铸工艺**：
1. **设计**：将器物分解为可铸造的部分
2. **制范**：为每部分制作陶范
3. **浇注**：分别浇注各部分
4. **组装**：将各部分组装（铸接、焊接）
5. **修整**：修整接缝，打磨光滑

**代表作**：
- 四羊方尊：羊头和身分铸
- 曾侯乙编钟：每件独立铸造
- 司母戊鼎：鼎身和鼎耳分铸

### 失蜡法（熔模铸造）

**工艺流程**：
1. **制蜡模**：用蜡制作器物模型
2. **涂浆**：在蜡模外涂陶泥浆
3. **干燥**：反复涂浆，干燥
4. **焙烧**：加热熔化蜡，形成型腔
5. **浇注**：浇注铜液
6. **清理**：清理陶范，取出铸件

**优势**：
- 可铸造极复杂造型
- 纹饰清晰精细
- 一次性成型

**应用**：
- 曾侯乙尊盘：极复杂造型
- 铜镜：精细纹饰
- 小型器物

### 浇注技术

**合金制备**：
- 铜、锡、铅按比例混合
- 在坩埚中熔化
- 炉温达1083°C（铜熔点）

**浇注系统**：
- **浇口**：铜液入口
- **冒口**：排气和补缩
- **排气道**：排出气体
- **浇道**：铜液通道

**浇注工艺**：
1. 预热陶范（防止铜液过早冷却）
2. 对准浇口
3. 倾入铜液
4. 冷却凝固
5. 开范取件

### 后期处理

**清理**：
- 去除浇口、冒口
- 打磨表面
- 去除毛刺

**修整**：
- 修整缺陷
- 补铸漏洞
- 打磨光滑

**装饰**：
- 镶嵌：镶嵌金银、绿松石
- 鎏金：表面镀金
- 错金银：嵌入金银丝
- 刻划：表面刻划纹饰

## 枯萎原因分析

### 社会变迁

**礼制变革**：
- 东周礼崩乐坏
- 传统礼制瓦解
- 青铜礼器需求减少

**东汉礼制**：
- 汉代建立新礼制
- 青铜礼器地位下降
- 陶器、漆器取代

**铁器兴起**：
- 铁器性能优于青铜
- 铁器成本更低
- 青铜转向实用器物

### 技术替代

**铁器优势**：
- 硬度高，韧性好
- 矿藏丰富，成本低
- 适合大规模生产

**铸造技术革新**：
- 铁器铸造技术发展
- 砂型铸造取代陶范
- 效率提升100倍以上

**现代技术**：
- 熔模铸造更精密
- 砂型铸造更高效
- 失蜡法工业化

### 口传技艺断裂

- 东汉后青铜匠师减少
- 魏晋南北朝战乱
- 许多技法永久失传

**传承中断**：
- 年轻一代不愿学习
- 需长期训练（10年以上）
- 需求消失导致转行

**知识载体消失**：
- 主要靠家族作坊口传心授
- 缺乏系统化文字记录
- 许多"秘技"从未形成文字

**失传的技法**：
- 陶范材料配比
- 制范温度控制
- 浇注时机判断
- 分铸接口技术

### 需求消失

**礼器需求消失**：
- 传统礼制瓦解
- 新礼制不再需要青铜礼器
- 需求暴跌

**转向实用**：
- 青铜转向铜镜、铜钱
- 小型器物只需简单技术
- 复杂技术无用武之地
