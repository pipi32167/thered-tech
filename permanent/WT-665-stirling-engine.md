# WT-665: 斯特林发动机 - 安静的外燃机

**领域**: 能源/机械工程

## 📜 简史
1816年，苏格兰牧师罗伯特·斯特林发明了这种外燃机，旨在替代当时危险的蒸汽锅炉。核心原理是通过封闭气体的周期性压缩和膨胀，利用温差产生动力。19世纪曾用于泵水和小型机械，20世纪在瑞典、荷兰得到民用应用（热电联产）。

## ⚰️ 枯萎原因
1. **功率密度低** - 相比内燃机，体积大但功率小
2. **响应迟缓** - 热惯性导致启动和变慢需要时间
3. **材料限制** - 需要长期承受高温高压的密封挑战
4. **成本劣势** - 制造精度要求高，无法与廉价的内燃机竞争
5. **石油时代** - 20世纪廉价燃料使内燃机统治一切

## 💡 当代启发

### 重生可能
斯特林发动机的三大优势在新时代变得珍贵：
- **安静** - 无爆炸燃烧，近乎静音，适合潜艇和军用
- **多燃料** - 任何热源都能驱动（太阳能、废热、生物质）
- **高效率** - 理论卡诺效率接近内燃机，实际已达40%

### 现代应用
1. **太阳能热发电** - 聚光太阳能+斯特林机（美国SunPower、瑞典Cleanergy）
2. **废热回收** - 工业废热、汽车尾气余热发电
3. **深海探测** - 核能+斯特林为无人潜航器提供数年动力
4. **家庭热电** - 瑞典已有数万户使用天然气驱动的微型CHP机组

### 创新警示
- **技术时机论** - 同样的技术在不同时代价值完全不同
- **长周期创新** - 有些技术需要200年才能找到合适场景
- **竞争环境决定命运** - 斯特林不是"输"给了内燃机，而是"不适合"20世纪
