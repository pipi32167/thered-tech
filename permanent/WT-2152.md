# WT-2152：古代波斯捕风塔技术

## 技术概述

**技术时期**：古埃及（公元前3000年）- 20世纪中叶（约5000年）
**技术领域**：建筑/环境控制/被动式制冷/通风技术
**技术类型**：自然通风技术/被动式制冷技术/绿色建筑技术

### 技术定义

古代波斯捕风塔技术（Windcatcher，波斯语：بادگیر‎，Badgir）是指通过建造高耸的塔状结构，利用风力将自然风引入建筑内部，并配合地下水渠系统实现被动式制冷通风的建筑环境控制技术。这是古代人类在没有电力的情况下创造的零能源制冷技术杰作。

### 核心特征

1. **零能源**：完全依靠自然力（风、地热），无需电力
2. **被动式**：建筑设计本身实现制冷，无需机械设备
3. **生态友好**：无碳排放，无污染
4. **地域适应**：适应干旱沙漠气候
5. **技术创新**：利用伯努利原理和烟囱效应
6. **文化符号**：成为中东建筑的标志性特征

## 历史发展

**早期技术**：
- 简单的通风井设计

**技术特点**：

## 技术原理详解

### 风塔结构

**塔身设计**：
- **高度**：通常5-15米，有的高达30米
- **形状**：方形、圆形、八角形
- **材料**：土坯、砖、石
- **壁厚**：厚墙隔热

**顶部开口**：
- **四向开口**：塔身四面都有开口
- **开口方向**：可调节，朝向主导风向
- **开口大小**：可调节，控制风量
- **防护**：顶部常有遮阳板

**内部结构**：
- **风道**：塔内设置四个独立风道
- **隔板**：隔板将塔内空间分隔
- **出口**：底部出口连接室内空间

### 工作原理

**捕风原理**：
1. 风吹向塔身
2. 被顶部开口捕获
3. 风进入塔内
4. 向下流动到室内

**伯努利原理**：
- 风速增加，压力降低
- 形成压力差
- 将空气吸入塔内

**烟囱效应**：
- 热空气上升
- 从塔顶排出
- 形成自然对流

**制冷原理**：
1. 风进入塔内
2. 通过地下水渠（坎儿井）上方
3. 地下水冷却空气
4. 冷空气进入室内
5. 降低室内温度

### 系统集成

**与坎儿井结合**：
- 坎儿井（qanat）是地下水渠系统
- 风塔建在坎儿井上方
- 风经过坎儿井被冷却

**与蓄水池结合**：
- 蓄水池储存冷水
- 风塔引入冷水蒸汽
- 增加湿度，改善舒适度

**与庭院结合**：
- 风塔将风送入庭院
- 庭院作为空气缓冲区
- 风从庭院进入室内

### 设计变体

**单向风塔**：
- 只有一个开口
- 朝向主导风向
- 用于特定风向地区

**四向风塔**：
- 四个开口
- 可捕捉任意方向的风
- 最常见的设计

**组合系统**：
- 多个风塔组合
- 分别用于不同房间
- 形成中央空调系统雏形

## 枯萎原因分析

### 技术替代

**电力空调优势**：
- **效率高**：制冷效率高，降温快
- **可控性强**：温度可精确控制
- **不受环境限制**：无风也能工作
- **便利性好**：操作简单

**机械通风优势**：
- **可靠性高**：机械风机稳定
- **风力大**：风力强，效果好
- **可控性强**：风量可调

**技术对比**：
| 指标 | 风塔 | 电力空调 |
|------|------|----------|
| 能源消耗 | 零 | 高 |
| 制冷效率 | 低 | 高 |
| 可控性 | 低 | 高 |
| 依赖性 | 依赖风力 | 依赖电力 |
| 成本 | 一次投入高，运行成本低 | 一次投入低，运行成本高 |
