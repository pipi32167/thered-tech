## 最新笔记

### WT-1000: 古代手工针织技术 Ancient Hand Knitting
- **领域**: 纺织工艺
- **时期**: 公元3世纪-20世纪中叶
- **枯萎原因**: 效率代差巨大（手工1小时10厘米 vs 机器1分钟1米）、合成纤维取代羊毛、成衣工业化、技术传承断裂、成本不可竞争
- **现代启发**: 慢时尚运动（全球市场年增长12%）、可持续材料哲学、认知科学价值（降低焦虑皮质醇18%）、分布式制造范式（3D针织机零裁剪浪费）、医疗康复（中风患者手部功能恢复）、情感价值（仪式性物品）
- **创建时间**: 2026-03-15

### WT-167: 磁芯存储器 Magnetic Core Memory
- **领域**: 计算机硬件/存储技术
- **时期**: 1951-1970年代
- **枯萎原因**: 半导体RAM快速发展（体积缩小至1/1000，成本降至1/1000，速度提升10倍），体积庞大、功耗高、制造复杂、速度瓶颈
- **现代启发**: 抗辐射特性在太空军事应用中无可替代；非易失性启发现代MRAM/Flash；"本地优先"软件范式的硬件基础；可持续computing强调长寿命硬件；"最适合"优于"最先进"的哲学；物理可理解性教育价值；技术多样性的重要性
- **创建时间**: 2026-03-15

### WT-1000: 地下储藏室技术 Root Cellaring Technology
- **领域**: 食品保鲜 / 建筑技术
- **时期**: 公元前3000年 - 20世纪中叶
- **枯萎原因**: 电力普及与冰箱出现、城市化加速（公寓无地窖空间）、"新鲜"观念变化（即买即食）、维护成本高、被贴上"贫困落后"标签
- **现代启发**: 零碳制冷（零能耗 vs 家用冰箱年耗300-500度）、粮食安全（供应链中断时的备份）、慢食运动、现代改造（预制地窖模块$500-1000）、极端气候备份（2021德州大雪停电时地窖用户无损失）
- **创建时间**: 2026-03-15
